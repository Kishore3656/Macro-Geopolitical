🔧 CUSTOMIZATION QUICK TIPS
─────────────────────────────────────────────────────────────────────────────────────────────────────
File: frontend/src/components/dashboards/UnifiedDashboard.tsx

Add new card:
  1. Copy a card div (lines ~45-72)
  2. Change className colors (bg-red-500 → bg-blue-500)
  3. Update icon (Brain → Heart, etc.)
  4. Change data binding (signal.confidence → spy.price, etc.)

Change colors:
  Find: bg-red-500/20, text-red-400, border-red-500/30
  Replace: bg-[yourcolor]-500/20, text-[yourcolor]-400, border-[yourcolor]-500/30

Add new table:
  1. Copy the bilateral/events table section
  2. Add new state: useState<YourData>(null)
  3. Add useEffect to fetch: api.yourEndpoint()
  4. Map over data and render rows

⚠️ TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────────────────────────────
Dashboard shows "Loading...":
  → Check backend is running: http://localhost:8000/docs
  → Check CORS enabled in api/main.py
  → Check NEXT_PUBLIC_API_URL in .env.local

Cards show null/"-" values:
  → Data not ingested yet - check ingestion scripts
  → API endpoint may be failing - test in browser
  → Example: curl http://localhost:8000/api/gti

CSS looks broken:
  → Rebuild: cd frontend && npm run build
  → Clear cache: Delete .next folder, restart dev server

Type errors on build:
  → Run: npm run type-check
  → Some pre-existing errors in api.ts (timeout parameter)
  → UnifiedDashboard.tsx should have no errors

🎓 TRADER'S WORKFLOW
─────────────────────────────────────────────────────────────────────────────────────────────────────

MORNING CHECK (30 seconds)
  1. Check AI Signal card - is it UP or DOWN?
  2. Check GTI Risk card - what's the threat level?
  3. Verify SPY Market Status - does it confirm?
  4. If GTI > 40, scan geopolitical events

BEFORE TRADE (2 minutes)
  1. Review Signal Table - recent predictions accurate?
  2. Check Confidence % - is it > 70%?
  3. Look at Critical Zones - any tensions escalating?
  4. Scan Geo Events - any breaking news?

DURING TRADE (Continuous Monitoring)
  1. Watch for new signals in the table
  2. Monitor GTI for threshold breaches
  3. Track event intensities for sudden spikes
  4. Cross-reference with sector performance
